# 지도 로딩·색상 조정 — 2026-09-24 KST

Mac mini Apple M4 / Metal, 1200×720 오프스크린 지도에서 로컬 PMTiles를 같은 순서로 열 화면 로딩했다. 명령은 `target/debug/mappa-map-demo --zoom-compare`다. `load_ms`는 타일 조회·MVT 해독·도형 준비·GPU 업로드를 포함하고 PNG 저장 및 화면 표시는 제외한다. 이전 수치는 변경 전 같은 명령의 한 번 측정이며 측정 간 편차가 있다.

원래 병목은 도형 준비였다. 폴리곤마다 새 임시 버퍼를 만든 뒤 결과를 복사하던 작업을 타일의 레이어별 버퍼로 직접 누적하도록 바꿨다. 개발 빌드에서도 지도 도형 처리 크레이트와 MVT 해독 크레이트를 `opt-level = 2`로 빌드한다. 이 설정은 개발 빌드의 컴파일 시간을 늘릴 수 있다. 지도 데이터와 좌표는 바꾸지 않았다.

별도 `target/debug/mappa-map-demo --street-benchmark`를 상록수 주변 (126.866778, 37.302813), z11.4에서 한 번 실행했다. 지도와 라벨을 포함한 첫 로딩은 155.6 ms, 로딩 후 120프레임은 중앙값 9.7 ms / p95 13.3 ms / p99 33.4 ms였다. 24px씩 이동하는 40프레임은 중앙값 10.0 ms / p95 12.1 ms / p99 31.7 ms였다. 타일 실패는 0개였다. 이 측정은 Metal 오프스크린이며 실제 창의 입력 지연 또는 iPhone 프레임 시간으로 해석할 수 없다.

기본 `Arcade` 색은 노란 배경 없이 땅을 차분한 회색, 물을 더 깊은 파랑, 녹지를 더 뚜렷한 초록으로 조정했다. 도로 외곽선의 명도 차이도 늘렸다. 확인 이미지: `artifacts/map-v0.3a/compare/sangnoksu-clear.png`, `artifacts/map-v0.3a/zoom/korea-network.png`.
