# 나주 canonical proof 정확도 판정

**판정: PARTIAL / 전체 지역 proof gate 미통과.** 검증된 사실: 나주시 원본 GeoJSON의 도로 중심선 3,827개와 유효 도로면 4,477개가 proof bbox `[126.69,34.99,126.78,35.08]`와 겹쳐 GeoDB에 들어갔다. 모든 feature에 provenance가 있다. 도로면 17개는 invalid polygon으로 [거부](../artifacts/map-v0.3c/naju-roads.rejected.json)했다. z10–z15의 실제 타일을 생성했고 각 줌에서 road 레이어 디코드를 확인했다. 지도 화면도 z14.6·z15.2에서 오류 없이 렌더링됐다. OSM/NE 원본은 이 빌드 경로에서 읽지 않는다.

**미검증:** 원본 ZIP에 `.prj`가 없어 EPSG:5186 변환은 가정이다. 제공기관의 CRS 확인과 독립 측량 기준점 50개가 없으므로 평균/p95 도로 위치 오차, 누락 도로, 교차로 연결률을 보고할 수 없다. 도로만으로 land/water·건물·철도·공원·지명·공공기관 완성도를 평가할 수 없다. 비교용 기존 OSM/NE 화면은 지역·줌·레이어가 달라 A/B 승패를 선언하지 않는다.

MVT extent 4096의 **이론적** 반 칸 반올림 오차는 나주 위도에서 z15 기준 축당 약 0.12m이다. 이는 타일 양자화만의 상한 추정이며 원본 좌표 정확도나 전체 화면 오차가 아니다. 실제 tile-boundary break, 접합점, source→화면 오차 계측은 아직 필요하다.

다음 gate: (1) 기관 CRS 확정, (2) 건물·수면 등 이용 조건이 확인된 원본 확보, (3) 도로/건물/수면 독립 참조점과 동일 카메라 A/B, (4) 교차로 topology 및 타일 경계 검사. 이 결과 없이는 전국·세계 확장 판정을 하지 않는다.
