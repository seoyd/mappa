# 나주 canonical proof 정확도 판정

**판정: PARTIAL / 전체 지역 proof gate 미통과.** 검증된 사실: 나주시 원본 GeoJSON의 도로 중심선 3,827개와 유효 도로면 4,477개, 국가데이터처 SGIS의 실제 읍면동 이름 14개, ESA WorldCover 2021의 영구수면 polygon 79개와 수목 피복 polygon 2,609개가 proof bbox `[126.69,34.99,126.78,35.08]`를 대상으로 GeoDB에 들어갔다. 총 11,006개 feature 모두 provenance가 있다. 도로면 17개는 invalid polygon으로 [거부](../artifacts/map-v0.3c/naju-roads.rejected.json)했다. z10–z15의 실제 타일을 생성했고 z12–z15에서 지명 14개/줌, z10–z15에서 영구수면, z14–z15에서 수목 피복 디코드를 확인했다. 지도 화면은 [수계·수목 z14.6](../artifacts/map-v0.3c/naju-water-tree-river-z14.png)에서 오류 없이 렌더링됐다. OSM/NE 원본은 이 빌드 경로에서 읽지 않는다.

**미검증:** 도로 원본 ZIP에 `.prj`가 없어 EPSG:5186 변환은 가정이다. SGIS 원본에는 `.prj`가 있어 EPSG:5179를 확인했다. 제공기관의 도로 CRS 확인과 독립 측량 기준점 50개가 없으므로 평균/p95 **실제 도로 위치 오차**, 누락 도로, 교차로 연결률을 보고할 수 없다. ESA 수면·수목은 2021년 10m 분류 결과라서 현재 하천 측량선·공원 경계의 대체가 아니다. 건물·철도·공원·역·공공기관 완성도를 평가할 원천이 없다. 비교용 기존 OSM/NE 화면은 지역·줌·레이어가 달라 A/B 승패를 선언하지 않는다.

MVT extent 4096의 **이론적** 반 칸 반올림 오차는 나주 위도에서 z15 기준 축당 약 0.12m이다. 이는 타일 양자화만의 상한 추정이며 원본 좌표 정확도나 전체 화면 오차가 아니다.

도로선의 **타일 경계**는 실제 PMTiles를 디코드해 인접 타일의 같은 등급 도로선이 경계를 지나는 좌표를 대조했다. 초기 산출물에는 z11·z12·z13에서 각각 1·4·2개의 허용 오차 초과 접점이 있었다. 타일마다 도로선을 경계 밖으로 MVT 32단위(원래 줌에서 4px) 더 유지한 뒤 z10–z15 전체에서 허용 오차 초과 접점이 0개였다. z14에는 10개, z15에는 25개의 접점이 서로 1 MVT 단위 이내에서 일치했다. 1단위는 원래 줌의 화면에서 0.125px에 해당한다. 감사 범위는 proof bbox 안의 도로 **중심선** 타일 접합이며, 도로면 폴리곤 접합·원본 교차로 연결·실제 도로 위치를 통과시킨 결과가 아니다.

[`audit_canonical_pipeline`](../crates/mappa-map-data/src/bin/audit_canonical_pipeline.rs)은 해시 순서에서 결정론적으로 선택한 **도로 100개**의 지역 안 선분 중점을 따라간다. 변환 GeoJSON → Rust 어댑터 좌표와 어댑터 → GeoDB feature는 100/100 정확히 같고, z15 LOD에 100/100 포함됐다. z15 MVT를 디코드하여 같은 등급의 가장 가까운 도로선까지 측정한 거리는 중앙값 0.036m, p95 0.088m, 최대 0.110m다. z15.2 카메라의 수학적 화면 투영 거리로는 중앙값 0.021px, p95 0.052px, 최대 0.065px다. MVT에 feature ID가 없으므로 근접한 다른 동일 등급 도로와의 혼동 가능성이 있다. 이 수치는 **SHP → GeoJSON 좌표계 변환, 실제 도로 측량 오차, raster 화면 픽셀의 위치 오차가 아니다.** 도로면 17개가 유효성 검사에서 빠진 구역은 별도 품질 검토가 필요하다.

다음 gate: (1) 기관 도로 CRS 확정, (2) 건물·철도·공원 등 이용 조건이 확인된 원본 확보와 공식 수계 비교, (3) 도로/건물/수면 독립 참조점과 동일 카메라 A/B, (4) 원본 교차로 topology 및 도로면·수면 타일 경계 검사. 이 결과 없이는 전국·세계 확장 판정을 하지 않는다.
