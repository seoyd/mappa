# Mappa 지도 원칙 (v0.3C)

Mappa가 소유하는 것은 **원천 자료를 검증·정규화해 만든 canonical GeoDB, 출처 이력, LOD 규칙, 타일 패키지, Rust 렌더러**다. 실제 도로·건물을 직접 측량했다는 뜻은 아니다. 원천 데이터 제공자의 권리와 표기 조건은 계속 적용된다.

운영 중 유료 지도 API, 외부 타일 서버, 상용 지도의 스크린샷 추출은 사용하지 않는다. 무료·합법 원천도 라이선스와 좌표계를 검증한 뒤 빌드 입력으로만 사용한다. 데이터가 없는 곳은 실제 지형처럼 채우지 않는다. 기존 OSM/Natural Earth 지도는 비교와 이전 데모를 위해 보존한다. `canonical-proof`는 이 둘을 열지 않는 별도 경로다. 현재 기본 세계지도는 여전히 Natural Earth 기반이므로 **세계 전체의 자체 DB 완성은 아님**을 구분한다.

지역 실증을 통과한 뒤 건물·수면·공원·지명 등을 합치고, 이후 세계 저밀도 패키지와 지역 상세 패키지를 설계한다. 출처가 다른 객체의 matching·fusion은 검증된 두 번째 원천이 생기기 전까지 실행하지 않는다.
