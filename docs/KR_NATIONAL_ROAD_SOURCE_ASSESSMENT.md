# 한국 전국 도로 원천 판정 — 2026-09-25

## 현재 결론

**전국 상세 도로 팩 미구축.** 공개 페이지에서 전국 후보는 확인했지만, Mappa canonical GeoDB에 넣을 원본 파일과 재배포 권리 확인이 아직 없다. 한국 나주의 기존 지역 실증은 별도이며, 원본 좌표계와 독립 위치 기준점 미확인으로 [S16 `NO_GO_SOURCE_COVERAGE`](MAP_V0_3C_GATE_AUDIT.md) 상태다.

[브이월드 저작권정책](https://www.vworld.kr/v4po_prcint_a006.do)은 공공누리 제1유형이 **부착된** 자료인지 확인하고, 표시가 없는 자료는 제공 담당 부서와 사전 협의하라고 명시한다. 브이월드 차도중심선 상세 페이지에 라이선스가 미지정이라고 표기되므로 사이트 전체의 일반 정책만으로 해당 ZIP의 변경·재배포 권리를 확정하지 않는다. 제공기관이 권리를 확인하거나 동일 원천의 명시적 제1유형 배포본을 찾기 전에는 다운로드 가능 여부와 별개로 제품 팩에 편입하지 않는다.

## 다음 게이트

1. 전국 차도중심선 원천의 변경·상업 이용·PMTiles 재배포 권리를 **해당 데이터셋 단위로** 확인한다. WFS의 제3자 권리 문구도 해소한다.
2. 허용 원본을 받으면 ZIP 전체 해시, 실제 `.prj`, SHP/DBF 행 수·필드, 전국 지리 범위를 고정한다. 웹 페이지에 적힌 CRS를 파일 자체의 검증으로 대신하지 않는다.
3. Rust EPSG:5179 변환·도로 종류 분류·출처 계보·타일 감사 후 독립 기준점과 교차로 연결성, Metal·iPhone 화면을 확인한다. 실제 도로 위치가 맞는지는 이 검증 뒤에만 판정한다.

현재까지 이 후보에서 Mappa에 추가한 도로 선형은 **0개**다. 이 문서는 원천 탐색 결과이며 구축 완료 보고가 아니다.
